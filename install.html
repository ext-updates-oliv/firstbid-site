Downloading FirstBid

Two Windows prompts show up the first time you run it — both are expected. Here's why, and what to click.

1. Browser says the file "isn't commonly downloaded"

Microsoft Edge/Chrome flags any new file that hasn't been downloaded many times yet — it's a popularity check, not a virus scan.

  1. Open the Downloads panel and find FirstBid-Setup-latest.exe
  2. Click "..." (or "See more") next to it
  3. Choose "Keep" (or "Download anyway")

2. "Windows protected your PC"

This is Microsoft Defender SmartScreen. It appears for any app that doesn't yet have a paid code-signing certificate — FirstBid is a small tool sold directly, not distributed through an app store, so it hasn't built up that reputation yet. It does not mean the app is unsafe.

  1. Click "More info"
  2. Click "Run anyway"
